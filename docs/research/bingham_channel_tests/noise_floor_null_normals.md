# Noise-floor null for the smallest eigenvalue of the normal orientation tensor T = (1/N) sum n_i n_i^T (LiDAR, PCA normals)

Conventions used below. n_i = unit normals (sign-free). v = the truly degenerate direction (corridor axis). e_i = tangent-plane error of normal i (small-angle vector, e_i perpendicular to n_i^0). s^2 = per-axis variance of e_i (so E[theta^2] = |e|^2 = 2 s^2 for isotropic noise). l1 = smallest eigenvalue of T. p = 3.
Labels: [Published] = taken from a fetched source (URL given; several fetches were read through a summariser tool, flagged where this matters). [Derived] = my derivation, steps shown. [Sim] = my own numerical check (scripts in `noise_floor_sims/`, same folder; numpy 2.4, scipy 1.17). [Memory] = standard textbook result I know but did not re-verify in this session; treat as unverified until checked.

## KQ1. Normal-estimation error: angular error vs range noise, neighbourhood size/radius, density, incidence, curvature

### Takeaway
For a plane-fit/PCA normal, tangent error along an in-plane axis u_m has variance sigma_n^2 / lambda_m (lambda_m = m-th in-plane eigenvalue of the neighbourhood scatter matrix, sum form), which for a uniform disc of radius r with k points gives E[theta^2] = 8 sigma_n^2 / (k r^2); this matches the scaling of Mitra & Nguyen's noise term (sigma/(r^2 sqrt(rho))) and their optimal-radius result r ~ sigma^(2/3) kappa^(-1/3). On a VLP-16, neighbourhoods are ring-dominated (very anisotropic), so the isotropic formula underestimates the floor, and the error along the corridor axis is large (rms ~0.1 rad in my simulation).

### Cited Findings
- Mitra & Nguyen: for a curve (R^2) the normal angle error bound is alpha <= c1*kappa*r + c2*sqrt(sigma_n/(eps^2 rho r^3)) + c3*sigma_n^2/r^2 (kappa = curvature bound, r = neighbourhood radius, sigma_n = noise std, rho = sampling density, eps = confidence parameter; c_i distribution-dependent constants); optimal radius r = Theta(1) sigma_n^(2/3) kappa^(-1/3) giving error Theta(1) kappa^(2/3) sigma_n^(2/3) — [Mitra, Nguyen & Guibas, Stanford copy](https://geometry.stanford.edu/lgl_2024/papers/mng-esnpcd-04/mng-esnpcd-04.pdf) (fetched via summariser; the symbol rendered as "²" in the summary is presumably epsilon — verify in PDF).
- Mitra & Nguyen, surfaces (R^3): (lambda2/lambda1)*alpha <= Theta(1) kappa r + Theta(1) sigma_n/(r^2 sqrt(eps^2 rho)) + Theta(1) sigma_n^2/r^2; optimal neighbourhood size r = [ 1/(kappa) * (d1 sigma_n sqrt(eps^2 rho) + d2 sigma_n^2) ]^(1/3) with empirically chosen d1 = 1, d2 = 4 — same source. (Bound on curvature-vs-noise trade-off; constants are not tight.)
- Jordan & Mordohai compare PlaneSVD, PlanePCA (mean-centred total least squares), VectorSVD, QuadSVD and variants adding reference-point anchoring (R), vector normalisation (N, each offset divided by its norm) and Gaussian distance weighting (W); at k = 20 noise-free average angular error is about 4.5 deg for the best variant (N) and ~4.6 deg for PlanePCA/PlaneSVD, rising to 8.04 deg at sigma_n = 0.3% of the bounding-box diagonal; "lowest error is achieved by N for k >= 20 for all values of sigma_n"; the paper gives little curvature/edge-specific analysis — [Jordan & Mordohai 2014](https://mordohai.github.io/public/Jordan_QuantEvaluationSurfaceNormalEstimation14.pdf) (summariser; synthetic non-LiDAR data, noise as fraction of object size, not directly transferable to VLP-16).
- Gelfand et al. (ICP stable sampling) state that noise in point positions and normals in flat areas "will overwhelm" contributions from informative features and that smoothing noisy data risks removing genuine features — [Gelfand, Rusinkiewicz et al. 2003](https://graphics.stanford.edu/papers/stabicp/stabicp.pdf).
- A LiDAR-specific robust-normal paper (urban LiDAR) exists — [Sensors 2019, 19(5):1248](https://www.mdpi.com/1424-8220/19/5/1248) — found in search only; contents not read.

### Inferences
- [Derived] Plane-fit normal covariance. Local frame (u1,u2,n); height model h_j = a u1_j + b u2_j + c with i.i.d. noise sigma_n along n. LS gives Cov(a,b) = sigma_n^2 (sum_j d_j d_j^T)^(-1), d_j = centred in-plane coordinates. Tangent error e = -(a,b). PCA (total least squares) gives the same first-order result: for scatter M = sum d d^T with eigenpairs (lambda_m,u_m), perturbation of the smallest eigenvector is delta n = -sum_{m=1,2} u_m (u_m^T dM n)/lambda_m; u_m^T dM n ~ sum_j (u_m.d_j) eps_j, variance sigma_n^2 lambda_m, so Var(component along u_m) = sigma_n^2 / lambda_m.
- [Derived] Uniform disc of radius r with k points: second moment r^2/4 per axis, lambda_m = k r^2/4, so s^2 = 4 sigma_n^2/(k r^2), E[theta^2] = 8 sigma_n^2/(k r^2), rms angle = 2.83 sigma_n/(r sqrt(k)). With k = pi r^2 rho this is ~ sigma_n/(r^2 sqrt(rho)), consistent with the Mitra-Nguyen noise term. Worked example: sigma_n = 0.02 m, k = 20, r = 0.15 m gives s^2 = 3.6e-3 (s = 0.06 rad, 3.4 deg per axis).
- [Derived/inference] sigma_n is the range noise projected on the surface normal, sigma_n = sigma_r cos(alpha) for incidence angle alpha (the in-plane component of the beam jitter does not move the plane to first order). At grazing incidence this shrinks sigma_n but spacing along the beam-projected direction grows by 1/cos(alpha), so the random error does not blow up; the real grazing-angle problems are systematic (range bias, mixed pixels, beam footprint) and are not covered by this formula. I did not find/read a published VLP-16 incidence-angle error model (see Gaps).
- [Sim] VLP-16-like ray-cast corridor (16 rings at -15..+15 deg in 2 deg steps, 0.2 deg azimuth, 3.0 m wide x 2.5 m high, returns within 20 m, N ~ 28.5k points, sigma_r = 0.02 m, PCA normals with k = 20): rms tangent error along the corridor axis is about 0.12 rad (mean T_vv of 0.019 under noise vs 0.006 noise-free). kNN neighbourhoods are nearly collinear along a ring (spacing 0.2 deg is ~7 cm at 20 m while ring spacing is 2 deg ~ 70 cm), so the "across-ring" direction is poorly determined, lambda_2 is tiny, and the isotropic formula and even the first-order plug-in (sigma_n^2/lambda_m with sigma_n from residual SS) give the wrong floor (residual-based plug-in predicted 7e-3 vs 1.9e-2 observed; the "ideal" plug-in blew up for k = 10 because lambda_2 -> 0). Conclusion: do not trust closed-form angular-error formulas for ring-structured neighbourhoods; calibrate by simulating the actual pipeline (KQ3).
- [Sim] Deterministic estimator bias exists even with zero noise: noise-free l1 = 4e-3 (k=20, r<10 m), 6e-3 (r<20 m), 7e-3 (r<40 m), 4e-4 (k=10), 8.8e-3 (k=40) — a discretisation/curvature bias of PCA on ring-sampled planes that is not a noise effect. So the null for "truly degenerate truth" is not zero even at sigma_r = 0 for such a pipeline.

## KQ2. Finite-sample bias and sampling distribution of the smallest eigenvalue of T under a degenerate truth

### Takeaway
If all true normals are perpendicular to v and tangent noise is zero-mean with per-axis variance s^2, then E[T_vv] = s^2 - 4 s^4 (isotropic Gaussian, exact to 4th order) and E[l1] = s^2 (1 - (p-1)/N) + O(s^4) = s^2(1 - 2/N): the noise floor is first-order s^2 (the mean x-component energy of the noisy normals), and minimising over directions costs only 2 degrees of freedom out of N. Its sampling distribution is a weighted chi-square: N*T_vv/s^2 ~ chi^2_N for i.i.d. homoscedastic errors, and chi^2_nu with nu = (tr C)^2 / tr(C^2) in general. Verified numerically for the i.i.d. case.

### Cited Findings
- Eigenvalue bias of sample covariance matrices is a standard topic: the sample eigenvalues are biased (largest up, smallest down) with first-order correction E[l_i] = lambda_i + (lambda_i/n) sum_{j != i} lambda_j/(lambda_i - lambda_j) (Lawley 1956; Anderson 1963) — [Memory]; related survey chapter [On the Bias in Eigenvalues of Sample Covariance Matrix (Springer)](https://link.springer.com/chapter/10.1007/978-3-319-77249-3_19) and [Nadler 2008, Finite sample approximation results for PCA, Ann. Statist.](https://projecteuclid.org/journals/annals-of-statistics/volume-36/issue-6/Finite-sample-approximation-results-for-principal-component-analysis--A/10.1214/08-AOS618.pdf) and [Paul, spiked covariance asymptotics](https://anson.ucdavis.edu/~debashis/techrep/eigenlimit.pdf) were surfaced by search but not read (so the formula above is not verified against them).
- No source found that treats the specific problem (scatter of noisy unit vectors with a zero true eigenvalue). The Lawley/Anderson formula is for sample covariance of Gaussian data around an unknown mean, which is a different bias mechanism (finite-N spreading of the spectrum) from the one here (additive noise floor).

### Inferences
All [Derived] unless marked [Sim].
1. Setup. n_i = (n0_i + e_i)/sqrt(1+|e_i|^2), e_i perpendicular to n0_i, E e_i = 0, v^T n0_i = 0 for all i. Then v^T n_i = v^T e_i / sqrt(1+|e_i|^2), so
   T_vv = (1/N) sum x_i^2/(1+|e_i|^2), x_i = v^T e_i.
2. Mean. Leading order E[T_vv] = (1/N) sum_i v^T Sigma_i v with Sigma_i = Cov(e_i). Isotropic Gaussian, 2D tangent: E[T_vv] = s^2 - E[x^2(x^2+t^2)] = s^2 - (3+1) s^4 = s^2 - 4 s^4. [Sim] N=5000, s=0.1: predicted 9.6e-3, observed 9.62e-3; N=5000, s=0.02: 3.994e-4 vs 4.000e-4.
3. Smallest eigenvalue vs fixed-direction value. T0 = diag(0, lam2, lam3) in the (v, y, z) basis, perturbation D = T - T0. Second-order: l1 = D11 - sum_{m=2,3} D1m^2/lam_m + ... D11 = T_vv. D1m = (1/N) sum_i x_i n0_{m,i} + O(e^2), mean 0, variance s^2 lam_m / N. So E[D1m^2/lam_m] = s^2/N for each m and E[l1] = s^2 - (p-1) s^2/N = s^2 (1 - 2/N) to this order. [Sim] N=200, s=0.05: mean l1 2.457e-3 vs predicted 2.475e-3; N=1000: 2.464e-3 vs 2.495e-3 (the remaining gap is the 4 s^4 term). Validity requires D1m << lam_m, i.e. s/sqrt(N lam_m) << 1; fails if T has a second near-zero eigenvalue.
4. If the degenerate subspace has dimension q > 1 (e.g. only two near-parallel wall families), the noise block in that subspace is s^2 * Wishart_q(N)/N and the smallest eigenvalue sits near the Marchenko-Pastur lower edge, s^2 (1 - sqrt(q/N))^2 (MP edge is textbook [Memory]; its use here is my inference). For q = 2, N = 1000 the factor is 0.91; negligible for large N_eff, matters only when N_eff ~ tens.
5. Distribution. Gaussian, independent, equal variance: N T_vv/s^2 ~ chi^2_N exactly (to first order), mean s^2, sd s^2 sqrt(2/N). [Sim] sd(l1) observed 2.41e-4 (N=200,s=0.05; pred 2.50e-4), 1.11e-4 (N=1000; pred 1.12e-4), 8.1e-6 (N=5000,s=0.02; pred 8.0e-6); 99th percentile of l1 vs s^2 chi2.ppf(.99,N)/N: 3.031e-3 vs 3.118e-3 (N=200), 2.743e-3 vs 2.767e-3 (N=1000), 4.183e-4 vs 4.188e-4 (N=5000). The chi-square quantile is slightly conservative (higher), as expected from the 2-df loss and 4 s^4 term.
6. Heteroscedastic (s_i^2 varying with range/incidence), independent: T_vv = (1/N) sum s_i^2 z_i^2. Satterthwaite: match mean m = (1/N) sum s_i^2 and variance 2 sum s_i^4 / N^2 to g chi^2_nu: nu = (sum s_i^2)^2 / sum s_i^4 (this is Kish's effective sample size with weights s_i^2), g = sum s_i^4 / (N sum s_i^2). Quantile: l1_null,99 ~ g chi^2_{nu, 0.99} (optionally minus the 2-df correction).
7. Correlated errors (overlapping neighbourhoods). Write x = A eps, eps = i.i.d. range noise of the P points, A sparse (row i = the in-plane regression weights of patch i projected on v). Then T_vv = (sigma^2/N) sum_l mu_l z_l^2 where mu_l = eigenvalues of A^T A: an exact (first-order) weighted chi-square mixture, evaluable with Imhof/Davies/Satterthwaite. Satterthwaite d.o.f.: nu = (tr C)^2 / tr(C^2) = (tr A^T A)^2 / tr((A^T A)^2), C = A A^T (can be estimated with Hutchinson trace probes without forming dense matrices). Key identity (Isserlis): for zero-mean bivariate Gaussians Cov(x_i^2, x_j^2) = 2 Cov(x_i,x_j)^2, so correlation enters squared: N_eff = N^2 / sum_ij rho_ij^2 (for equal variances), not N^2/sum rho_ij.
8. Non-Gaussian errors: Var(T_vv) = (1/N^2) sum_ij Cov(x_i^2, x_j^2); for independent errors with excess kurtosis kappa4 = E x^4/(E x^2)^2: Var = (kappa4 - 1) s^4/N, so nu_eff = 2N/(kappa4 - 1). Heavy-tailed normals (edges, mixed pixels) can make chi-square quantiles anti-conservative; use the empirical kurtosis of v^T n_i or bootstrap instead.
9. [Sim] Real pipeline (VLP-16-like corridor above, k=20, N~28.5k, one scan): sd of l1 across independent noise draws is 2.7e-4 on a mean of 1.9e-2 (1.4%); i.i.d. theory predicts 1.5e-4, so empirical N_eff ~ 8.5k = N/3.3 (design effect ~3.3). Within-scan sampling variability is tiny relative to the floor; the uncertainty that matters is the mean level (sigma_r, k, geometry, deterministic bias).
10. [Sim] The floor is not simply proportional to sigma_r^2 nor additive to the noise-free value: excess l1 over the noise-free value divided by sigma_r^2 was 163, 56, 33, 38 for sigma_r = 0.005, 0.01, 0.02, 0.03 m (k=20, r<20 m). So scale-by-sigma^2 extrapolation from one sigma_r is unreliable for ring-structured kNN; simulate at the actual sigma_r.

### Gaps
- Lawley/Anderson/Muirhead formulas not re-verified from a fetched source; they are not needed for the above (derivations are self-contained) but cite them only after checking.
- No published empirical study of chi-square/Satterthwaite coverage for quadratic forms of normals found; the coverage evidence here is only my i.i.d. simulation (Sim1) and one VLP-16-like scene.
- Non-isotropic noise (anisotropic Sigma_i) handled only via the v^T Sigma_i v formula; the 3D third-order (skew) terms were not analysed.

## KQ3. Practical calibration of the noise floor (parametric bootstrap, subsampling, split calibration) — concrete recipe

### Takeaway
Because analytic plug-ins fail for ring-structured kNN neighbourhoods (KQ1 [Sim]) and the noise-free pipeline itself has a non-zero l1, the defensible null is a parametric bootstrap through the full production pipeline on a simulated truly-degenerate scene built from the real scan geometry, optionally cross-checked by a conformal split calibration on real degenerate stretches. Recipe below; all steps are my proposal and none is a published standard.

### Cited Findings
- No published recipe for calibrating the noise floor of an orientation-tensor eigenvalue in LiDAR degeneracy detection was found. The closest ICP-side practice is Monte-Carlo/learned covariance calibration: CELLO-3D samples 5,000 ICP runs per point-cloud pair over 1,020 pairs (5.1 M registrations) and learns a regression from point-cloud descriptors to covariance — [Landry et al. 2019](https://norlab.ulaval.ca/pdf/Landry2019.pdf) (summariser).
- Brossard et al. propagate sensor noise and initialisation uncertainty with an unscented transform (12 sigma points instead of 65 Monte-Carlo samples) — [Brossard, Bonnabel, Barrau, arXiv 1909.05722](https://arxiv.org/pdf/1909.05722) (summariser).
- A recent preprint argues that degeneracy labels/thresholds on unnormalised Hessian spectra are frame-dependent and proposes a dimensionless point-displacement metric M = sum J_i^T J_i with eigenvalues in [0,1] and a fixed threshold tau = 1e-2; per the summary it does not address noise bias of the eigenvalues — ["Degenerate in Whose Frame?", arXiv 2608.15532](https://arxiv.org/html/2608.15532) (single recent preprint, read only via summariser; not peer-reviewed as far as I know).

### Inferences

**Recipe R1 (primary): parametric bootstrap through the production pipeline** [my proposal; steps validated in simulation only]
0. Choose v from data (eigenvector of l1, or the common direction of the fitted planes) and state the null: "all surfaces parallel to v". Statistics: T_vv and l1.
1. Build the degenerate surrogate of each scan: RANSAC-fit the dominant planes; re-fit them constrained parallel to v (project plane normals onto v-perp). Optionally keep a roughness term (add the real residual spread) to avoid an over-smooth null.
2. Keep the real sampling geometry: for every real return j (ring, azimuth, dropout pattern) take its beam direction d_j; set the range to the ray-plane intersection with the surrogate; add eps_j ~ N(0, sigma_r^2) along the beam. sigma_r: estimate from range residuals to the fitted planes at small incidence (sigma_r ~ resid_sd/cos(alpha)); use the datasheet only as a sanity check.
3. Run the exact production pipeline (same k/radius, ring handling, filters, robust weights, any normal-orientation or planarity gating, same T assembly), obtaining l1^(b) and T_vv^(b), b = 1..B, B >= 200 (cost is one kNN+eigh per draw).
4. Null summary: mean mu0, sd, 99th percentile q99. Report noise-free value l1^(0) (deterministic estimator bias) separately; it is part of the null.
5. Robustness band: repeat with sigma_r x {0.75, 1, 1.5} and k +/- 5; use the maximum q99 as the conservative threshold, because [Sim] between-draw sd (~1.4% of mean) is far smaller than the model-misspecification uncertainty in the level.
6. Windows of W scans: independent range noise across scans means the mean floor mu0 does not average down (deterministic bias also persists); only the sd shrinks ~1/sqrt(W). If T is a weighted sum over scans or voxels, use Kish N_eff = (sum w)^2/sum w^2 for the sd. Do not shrink the floor by W.
7. Decision rules.
   - "Significantly informative along v": reject degeneracy iff l1_hat > q99_null (calibrated per scene/range profile). Under H0 the false-alarm rate is <= 1% per independent window (check empirically, below).
   - Physical-information test: debiased information T_vv,excess = max(0, l1_hat - mu0); Fisher information along v in metres is N_eff-type scaled: sigma_v >= sigma_r / sqrt(N * T_vv,excess) (CRLB form, KQ5). Required precision sigma_req implies threshold T_vv >= sigma_r^2/(N sigma_req^2); e.g. N = 28,000, sigma_r = 0.02, sigma_req = 0.05 m gives 5.7e-6. [Derived arithmetic]
   - Note [Sim-based inference]: that physical threshold (~1e-5) is 3 orders below both the noise floor (~2e-2) and the null's q99-minus-mean spread (~1e-3 in my scene); a raw l1 can therefore only certify precision of roughly sigma_r/sqrt(N*1e-3) ~ 4 mm per scan, i.e. it certifies "informative" conservatively and cannot resolve small true T_vv. Using raw l1 against a metre-level threshold without subtracting the floor is meaningless: floor 0.0176-0.019 gives a spurious claimed sigma_v = 0.02/sqrt(28000*0.019) ~ 0.9 mm for a truly degenerate scene. This is the mechanism behind "noise-fitted normals manufacture precision"; it is consistent in direction (not verified in magnitude) with the project's 6x observation.

**Recipe R2 (analytic cross-check, cheap)**: per-point s_i^2 = sigma_n,i^2 * sum_m (v.u_im)^2/lambda_im with sigma_n,i^2 = lambda_i3/(k-3) (residual SS of the plane fit has k-3 d.o.f.) [Derived; standard LS fact]; floor = mean s_i^2; quantile via Satterthwaite with nu from KQ2 item 6-7. Valid only when neighbourhoods are well-conditioned in-plane (lambda_i2 not << lambda_i1). [Sim] it under-predicted the VLP-16-like floor by ~2.5x at k=20 and diverged at k=10; use R2 only as a sanity check or for isotropic (e.g. dense/solid-state or voxel-based) normal estimators.

**Recipe R3 (empirical split calibration, conformal)**: pick m non-overlapping time windows of real data that are independently known to be degenerate for v (surveyed straight corridor stretches, no doors/pillars); compute l1_hat per window; hold out test windows; threshold = the ceil((m+1)(0.99))-th smallest calibration value (split-conformal order statistic; valid under exchangeability of windows — [Memory], not verified here; with temporally autocorrelated windows use blocks and block-exchangeability). Caveat: this null includes real small structure and any unmodelled systematics, so it is an upper envelope (more conservative than R1). Needs m >= 100 for a 99% threshold to be non-trivial.

**Recipe R4 (cross-fitting / replicate debiasing)** [my proposal, partly validated in sim]: build normals twice for the same locations from independent noise (two scans of a static scene, or alternating-rank halves of each neighbourhood), form T_AB = (1/N) sum n_i^A (n_i^B)^T and take l1 of (T_AB + T_AB^T)/2. Because e^A, e^B are independent and zero-mean, E[T_AB] has no noise-variance term (first order), so the null is centred on the estimator's deterministic bias rather than s^2 and fluctuates with sd ~ s^2/sqrt(N). [Sim] two independent noisy scans (VLP-16-like corridor, k=20): cross-fit l1 = 9.5e-3, 9.6e-3, 9.5e-3, 1.0e-2 for sigma_r = 0.005, 0.01, 0.02, 0.03 m (sd 4e-5 to 3e-4), i.e. the sigma-dependent part (self-T l1 = 1.0e-2, 1.2e-2, 1.9e-2, 4.1e-2 over the same sigmas) is removed. The residual 9.5e-3 is a deterministic estimator bias (not equal to the noise-free 6.1e-3), so a simulated baseline is still required. Alternating-rank halves double the per-half variance and need a check that the halves are not spatially correlated.

**Validation / diagnostics on real data (use before trusting any null)**
- On surveyed degenerate stretches the fraction of windows with l1_hat > q99_null should be ~1%; mean(l1_hat)/mu0 should be ~1. Ratio >> 1 means unmodelled noise (sigma_r too small, rolling-shutter/motion distortion) or real structure; << 1 means over-smooth null.
- Dose-response check (SIMEX-like [my inference]): add extra synthetic range noise sigma_x to real data in a degenerate stretch; the shift of l1_hat should follow the simulated null curve.
- Report q99, mu0, N_eff (design effect) and the sigma_r/k used with every threshold.

### Gaps
- No empirical data from the project's own scans were available; all numerical illustrations come from my VLP-16-like synthetic corridor (3.0 m x 2.5 m, ring/azimuth pattern as stated, no motion distortion, no mixed pixels, no incidence-dependent bias), and quantitative floor levels will differ for the real sensor/pipeline.
- Conformal/split-calibration validity under autocorrelated LiDAR windows not checked against a source.
- Did not test the heavy-tail (edges, mixed-pixel) regime or robust-weight selection effects numerically.

## KQ4. Effective sample size under spatial correlation, and effect of robust weights and edge/plane mixtures

### Takeaway
N_eff for the quadratic form T_vv is N^2 / sum_ij rho_ij^2 (correlation enters squared), computable exactly from the neighbourhood graph; in my simulated VLP-16 scene with k=20 it was ~N/3.3. Robust weights change the floor to a weighted mean and N_eff to a Kish-type size, but weights that depend on the noisy normals induce selection bias and invalidate chi-square null; edge mixtures at corners parallel to v stay perpendicular to v, so they do not add to the floor except through variance/kurtosis.

### Cited Findings
- Jordan & Mordohai find normalised (N) and Gaussian-distance-weighted (W) variants of the PCA covariance, M^(N) = sum (q-q_bar)(q-q_bar)^T/||q-q_bar||^2 and M^(W) = sum exp(-||q-q_bar||^2/(2 sigma^2)) (q-q_bar)(q-q_bar)^T, to be among the most noise-robust at k >= 20 — [Jordan & Mordohai 2014](https://mordohai.github.io/public/Jordan_QuantEvaluationSurfaceNormalEstimation14.pdf) (summariser).
- Mitra & Nguyen's formula carries a curvature term proportional to r, i.e. larger neighbourhoods cut noise error but add bias across edges/curvature (optimal r trade-off above) — [Mitra, Nguyen & Guibas](https://geometry.stanford.edu/lgl_2024/papers/mng-esnpcd-04/mng-esnpcd-04.pdf).
- I found no published treatment of effective sample size for tensors/scatter built from overlapping-neighbourhood normals.

### Inferences
- [Derived] Overlap correlation. If e_i = a_i^T eps (linear in the range-noise vector), rho_ij = a_i.a_j / (|a_i||a_j|), nonzero when neighbourhoods share points, and N_eff = N^2/sum_ij rho_ij^2 (KQ2 item 7). Overlapping windows of k points share ~k-fold the data, so for strongly smoothed normals rho_ij can be large over many j; with k=20 [Sim] gave N/3.3. Increasing k reduces s^2 but increases the correlation length, so the floor and the variance of the floor move in opposite directions: it is the floor level (bias) that matters for the test, because between-draw sd was only ~1.4% of mean.
- [Derived] Weighted tensor T_w = sum w_i n_i n_i^T / sum w_i with weights independent of the noise: floor = sum w_i s_i^2 / sum w_i; Satterthwaite with weights w_i s_i^2 gives nu = (sum w_i s_i^2)^2 / sum w_i^2 s_i^4; Kish size (sum w)^2/sum w^2 when s_i equal. Down-weighting far/low-planarity points reduces the floor if those have large s_i^2 (it is a design lever for lowering the noise floor).
- [Derived] Weights that depend on the noisy normal or fit residual (planarity, Huber on residual, RANSAC inlier flags) are functions of e_i; they truncate the tails of x_i and can shift E[T_vv] below s^2 or distort it unpredictably, so chi-square/Satterthwaite is invalid; parametric bootstrap through the same weighting (Recipe R1 step 3) is the only safe route.
- [Derived] Weighted LS plane-fit covariance is a sandwich, Cov = sigma^2 (sum w d d^T)^(-1) (sum w^2 d d^T)(sum w d d^T)^(-1) >= the unweighted-optimal value when the noise is homoscedastic, so robust (down-weighting) fits trade extra noise floor for outlier resistance.
- [Derived] Corner/edge mixtures. A PCA patch straddling two planes with normals n_a, n_b gives a normal in the span of n_a, n_b (when the patch is not noise-dominated), hence v^T n = 0 whenever both planes are parallel to v. So wall-floor edges in a prismatic corridor do not raise the x-component floor except through bigger s^2 (patch contains two orientations, residual larger, in-plane spread asymmetric). A mixture with one oblique plane (door frame, end wall) has a genuine x-component: real signal, but in a PCA normal it is biased/blurred and cannot be told from the noise floor on a per-point basis; it enters T_vv as a heavy-tail contribution (raises kurtosis, so use R1 with real roughness or R3 rather than chi-square).
- [Sim] Deterministic ring-sampling bias (KQ1) likewise adds a non-noise component of l1 of the order of 4e-3 - 9e-3 depending on k and range limit.

### Gaps
- Heavy-tail/edge effects on the l1 null were not simulated; no source found on robust-weighted orientation tensors with a noise floor.
- Correlation structure was estimated only via simulation variance ratio (N_eff ~ 8.5k), not by explicit construction of A, so the 3.3 design effect is approximate.

## KQ5. Information-theoretic view: localizability criterion in metres; overconfidence of Hessian-based covariance; inflation factors

### Takeaway
Published work agrees that the raw Hessian/Fisher covariance (sigma^2 H^-1, i.e. Censi's closed form) is badly over-optimistic, by orders of magnitude on 3D data, and fixes it by adding unmodelled error sources (bias, initialisation, re-association) or learning a correction; I found no source that models normal-estimation noise inflating the Hessian eigenvalue along a degenerate direction, or that gives a corridor-specific inflation factor for a normal-fitted Hessian. The project's ANEES 48 vs ~3 equals a covariance inflation of 16 (std x4) by arithmetic.

### Cited Findings
- Censi's CRB for range-finder localisation: Fisher matrix depends on the expected readings and on the orientation of the surfaces at sensed locations; under-constrained situations are singularities whose kernel is the direction of maximum uncertainty; covariance bounded below by the inverse Fisher matrix — [Censi, CRB for localization](https://censi.science/research/robot-perception/crb-localization/) (page summary; the 2007 ICRA paper itself not read).
- Censi's closed-form ICP covariance is Cov = sigma^2 A^-1 with A the Hessian at convergence; it assumes white sensor noise only and is "widely considered as overoptimistic" — [Brossard et al., arXiv 1909.05722](https://arxiv.org/pdf/1909.05722) (summariser).
- Brossard et al. Table 1 (Stairs sequence, normalised norm error, target ~1): Censi 10^3 (translation) and 10^4-10^5 (rotation); Monte Carlo 10^3 and 10^2; proposed 4.2 and 34; trajectory Mahalanobis for the proposed 1.0-2.3 (translation), 2.3-9.8 (rotation). Their model: Q_icp = (I-J) Q_ini (I-J)^T + G Q_sensor G^T with G Q_sensor G^T = sigma^2 A^-1 + A^-1 B cov(b) B^T A^-1; assumed ~5 cm bias std (Hokuyo characterisation); the bias term trace is ~2.6 cm vs ~0.2 cm for white noise, i.e. ~13x — the summariser stated these; verify against the paper before quoting — same arXiv source.
- CELLO-3D: Censi's estimate is "largely optimistic" in 3D; KL divergence of single-pair predictions: Censi 9.19e7 (Apartment) and 7.65e7 (Stairs) vs CELLO-3D 26.6 and 27.0; identifies point re-association (objective as a large number of plateaus), sensor noise (direct effect plus the re-associations it provokes) and geometric constraints (featureless hallways give multimodal, large-covariance directions) as the error sources — [Landry et al. 2019](https://norlab.ulaval.ca/pdf/Landry2019.pdf) (summariser).
- Gelfand et al.: Hessian of point-to-plane error is C = sum [(p x n); n][(p x n); n]^T; stability is the condition number lambda_max/lambda_min; small eigenvalues are sliding directions; noise in positions and normals can overwhelm informative features — [Gelfand et al. 2003](https://graphics.stanford.edu/papers/stabicp/stabicp.pdf).
- X-ICP: localizability detection from scan-to-map correspondences analysed against the principal directions of the optimisation, with a constrained ICP that stops drift in weakly constrained directions; no thresholds or noise analysis visible in the abstract — [X-ICP, arXiv 2211.16335](https://arxiv.org/abs/2211.16335v4) (abstract only). Zhang et al.'s degeneracy factor, X-ICP and Hinduja et al. use frame-dependent unnormalised spectra, per the critique in [arXiv 2608.15532](https://arxiv.org/html/2608.15532) (single preprint, summariser).

### Inferences
- [Derived] Point-to-plane translational information along unit v is I_v = (1/sigma^2) sum_i (v.n_i)^2 = N T_vv/sigma^2, CRLB sigma_v >= sigma/sqrt(N T_vv) (this is the Fisher form implicit in Censi's CRB, Gelfand's Hessian with the rotation block dropped). If T_vv is computed from noisy normals, E[T_vv] = true T_vv + s^2 under degeneracy, so the plug-in CRLB reports sigma_v ~ sigma/(s sqrt(N)) instead of infinity. Illustration with my simulation numbers (sigma = 0.02 m, N = 28,000, T_vv = 0.019): 0.9 mm. Ratio of claimed to true information is unbounded in the degenerate limit, which is why a floor subtraction (Recipe R1) is needed before using the CRLB form.
- [Derived arithmetic] ANEES 48 vs expected 3 (translation, dof 3): NEES scales as 1/(covariance scale), so the covariance must be inflated by 48/3 = 16 (std x4) to be consistent, if the error is uniformly mis-scaled. In a corridor the mis-scaling is direction-specific (largest along v), so a scalar inflation is the wrong correction: replace T_vv by max(T_vv - floor, 0) in the information along v and add the remaining ICP model errors (bias, reassociation) as separate terms.
- [Inference] The published inflation proposals are (i) add bias term (Brossard), (ii) add initialisation uncertainty, (iii) learn the map from geometry descriptors to covariance (CELLO-3D). None targets the normal-estimation noise floor of the Hessian directly; the null/floor subtraction of this note would be complementary, not a substitute.

### Gaps
- Not read directly (only via search listings/abstract/summariser): Censi 2007 ICRA CRB paper and closed-form covariance paper, Prakhya et al., Gelfand's treatment of noise beyond the one statement, X-ICP full text (thresholds, exact definition of localizability), Zhang's degeneracy paper, Segal GICP.
- The Brossard 2.6 cm vs 0.2 cm / 13x claim and Table 1 numbers are from a summariser; verify before citing. The 2608.15532 preprint (arXiv ID implies August 2026) is a single, recent, non-verified source.
- No published inflation factor specific to corridors or to normal-noise-induced Hessian bias was found; no source found that reports ANEES values like 48 vs 3 for LiDAR corridors.
