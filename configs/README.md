# configs/: per-sequence files that live inside the containers

| Folder | Files | Goes to |
|---|---|---|
| `multifloor/` | `multifloor_aloam.launch`, `multifloor_velodyne_convert.launch` | `switchslam_gpu_v2:/root/` |
| | `multifloor_config.yaml` (VINS-Mono) | `vinsmono_test:/root/catkin_ws/src/VINS-Mono/config/` |
| `cave02/` | generated VINS-Mono config, A-LOAM launch, extrinsics for Cave02 | same places, written by `fusion_v4/setup_sequence.sh` |
| `templates/` | an example `seq.env` (Cave02) | `~/runs_<name>/seq.env` |

GEODE's files are in `../fusion_v4/geode/`. Corridor02 and Long Corridor configs are generated by `setup_sequence.sh` from the SubT-MRS calibration files; the generated copies from the working laptop are collected by `../tools/capture_environment.sh`.
