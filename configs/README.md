# configs/: per-sequence files that live inside the containers

Copied from the working containers on 22 Oct 2026. How and where to install them: [`docs/setup/INSTALL.md`](../docs/setup/INSTALL.md), section 5.

| Folder | Contents |
|---|---|
| `multifloor/` | A-LOAM launch (two variants), Velodyne packet converter launch, VINS-Mono config |
| `corridor/` | Long Corridor: VINS-Mono config, A-LOAM launch, converter launch, extrinsics |
| `corridor2/`, `cave02/` | VINS-Mono config, A-LOAM launch, extrinsics (generated by `fusion_v4/setup_sequence.sh`) |
| `geode/` | A-LOAM launch for GEODE alpha (VINS-Mono config and extrinsics are in `../fusion_v4/geode/`) |
| `farm/` | monocular VINS-Mono config of the generation-1 Gazebo farm study |
| `genz/` | `genz_frozen.yaml`, the frozen GenZ-LIO configuration generated by `fusion_v4/genz/make_genz_config.py` |
| `seq_env_examples/` | the `seq.env` files of the original laptop for each sequence (GEODE, Corridor02, Cave02, Long Corridor). Paths inside are those of that machine - adapt `BAG_DIR`, `GT`, `OUT_DIR` |
| `templates/` | an earlier annotated Cave02 `seq.env` example |
